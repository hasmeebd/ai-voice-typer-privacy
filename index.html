AI Voice Typer: Privacy Policy

Publisher: OOFFOO Dev · Effective: 14 November 2026

AI Voice Typer turns your speech into text and types it into the app you are using. This page explains exactly what data the app handles. In short: we (OOFFOO Dev) receive no data at all. There are no accounts, no analytics, no ads and no servers of ours.

1. What is sent, and to whom

When you record, the app sends the following directly from your PC to the Google Gemini API (generativelanguage.googleapis.com), using the API key you provide:

  • the audio you recorded;
  • your settings that shape the result: spoken languages, translation target and your custom words;
  • with "Type while I speak" on: up to the last 300 characters typed in the previous 20 seconds, so the next phrase continues correctly.

Nothing is sent when you are not recording. Google processes this data under its own terms: the Gemini API Terms of Service and the Google Privacy Policy. Under those terms, Google may use content sent with a free-of-charge API key to improve its products. If that matters to you, use a key with billing enabled, or do not dictate sensitive information.

2. What stays on your PC

  • API key: stored in Windows Credential Manager, never in a file and never sent anywhere except Google.
  • Settings: a settings file in the app's own data folder.
  • History: your dictations (text, time, mode and the window title they were typed into), up to 1,000 items, in the app's data folder. You can delete items, clear the list, or turn history off in Settings.

Uninstalling the app removes its data folder. The API key can be removed in Windows Credential Manager (entry gemini-api-key.ai-voice-typer).

3. Microphone

The app records only while you hold the push-to-talk key or after you start a recording. If "Keep microphone ready" is on, the microphone stays open so recording starts instantly. In that state the app keeps only the last half second of audio in memory, overwriting it continuously. It is never saved or sent unless you start a recording. Windows shows its microphone icon while the microphone is open. You can turn this off in Settings.

4. Keyboard

Push-to-talk needs to know when you press and release one key (Right Alt by default). For this the app uses a Windows keyboard hook that checks each key press for that one key only. Every other key passes through untouched and is never stored, logged or sent. When you click "Change key" in Settings, the app reads only the next key you press, to set it. You can turn push-to-talk off in Settings, which removes the hook completely.

5. Clipboard

To type text, the app briefly places it on the clipboard, pastes it, and then restores your previous clipboard text. Text the app types is excluded from Windows clipboard history and cloud clipboard.

6. Children

The app is not directed at children under 13 and does not knowingly collect data from them.
